# Spec Delta: podcast-serving

## ADDED Requirements

### Requirement: Обложки выпусков раздаются по стабильному URL

`GET /cover/{номер}` и `GET /cover/{номер}/{имя}` MUST отдавать файл обложки выпуска с `Content-Type` по расширению и заголовком кэширования как у статики; отдача MUST NOT учитывать счётчик скачиваний. Обложка имеет канонический абсолютный URL вида `{base-url}/cover/{номер}/{NNN-slug}.{ext}`, где slug — транслит заголовка выпуска; имя в URL декоративно: запрос с любым именем (и без него) обслуживается одинаково. Неизвестный номер и выпуск без обложки MUST давать 404.

#### Scenario: Обложка отдаётся

- **WHEN** у эпизода 7 задана обложка `oblozhka.jpg`, запрошен `GET /cover/7/007-slug.jpg`
- **THEN** ответ 200, `Content-Type` соответствует расширению, файл совпадает с исходным, счётчик скачиваний не изменился

#### Scenario: Короткий адрес

- **WHEN** запрошен `GET /cover/7`
- **THEN** ответ 200 с тем же файлом обложки

#### Scenario: Обложки нет

- **WHEN** у эпизода 6 обложка не задана, запрошен `GET /cover/6`
- **THEN** ответ 404

#### Scenario: Неизвестный выпуск

- **WHEN** запрошен `GET /cover/999`
- **THEN** ответ 404

## MODIFIED Requirements

### Requirement: Страница выпуска

`GET /episodes/{номер}` MUST возвращать страницу выпуска: заголовок, номер, дата, участники, единый счётчик, полные шоу-ноуты, плеер с главами, действия скачивания с размером и атрибутом `download`, ссылка на YouTube, действие «поделиться» и переходы к предыдущему и следующему выпуску. Если у выпуска задана обложка, страница MUST показывать её в заголовочном блоке страницы. Неизвестный номер MUST давать 404. Страница MUST содержать канонический URL выпуска. Выпуск без аудио MUST отображаться без плеера.

#### Scenario: Полная страница выпуска

- **WHEN** эпизод 7 имеет аудио, видео, описание и главы, запрошен `GET /episodes/7`
- **THEN** ответ 200, страница содержит заголовок, дату, участников, полные шоу-ноуты, плеер с главами, ссылки «скачать» на именованные URL с размерами и атрибутом `download`

#### Scenario: Обложка на странице выпуска

- **WHEN** у эпизода 7 задана обложка, запрошен `GET /episodes/7`
- **THEN** страница содержит `<img>` с каноническим абсолютным URL обложки выпуска

#### Scenario: Обложки нет

- **WHEN** у эпизода 6 обложка не задана, запрошен `GET /episodes/6`
- **THEN** страница отдаётся успешно, `<img>` обложки выпуска отсутствует

#### Scenario: Неизвестный выпуск

- **WHEN** запрошен `GET /episodes/999`
- **THEN** ответ 404

#### Scenario: Поделиться выпуском

- **WHEN** на странице выпуска 7 нажато «Поделиться», браузер поддерживает Web Share API
- **THEN** в системный диалог передаются заголовок выпуска и абсолютный URL `/episodes/7`

#### Scenario: Переходы между выпусками

- **WHEN** в индексе есть выпуски 6, 7 и 9, запрошен `GET /episodes/7`
- **THEN** страница ссылается на выпуск 9 как следующий и на выпуск 6 как предыдущий по порядку публикации

#### Scenario: Выпуск без аудио

- **WHEN** эпизод 5 имеет только видеоноситель, запрошен `GET /episodes/5`
- **THEN** страница отдаётся успешно, аудиоплеер отсутствует, ссылка на скачивание видео присутствует

### Requirement: Архив выпусков

`GET /episodes` MUST возвращать архив всех выпусков от новых к старым компактными строками без поиска и фильтров: миниатюра обложки (когда обложка задана, вместо номерного бейджа; иначе номер), дата, заголовок, участники, длительность аудио, единый счётчик (когда больше нуля) и переход на страницу выпуска. Длительность MUST быть помечена иконкой часов, единый счётчик — иконкой и доступной подписью, объясняющей смысл числа. Строка выпуска с аудио MUST содержать быстрые действия «слушать» и «скачать» аудиофайл; выпуск без аудио — без них, со ссылкой на свою страницу.

#### Scenario: Полный список

- **WHEN** в индексе 49 выпусков, запрошен `GET /episodes`
- **THEN** страница содержит все 49 выпусков от новых к старым, у каждого — номер или миниатюра, дата, заголовок и ссылка на страницу выпуска; на странице нет поля поиска и фильтров

#### Scenario: Миниатюра в архиве

- **WHEN** у эпизода 7 задана обложка, у эпизода 6 — нет, запрошен `GET /episodes`
- **THEN** строка эпизода 7 содержит миниатюру с URL обложки выпуска, строка эпизода 6 — номер без миниатюры

#### Scenario: Быстрое прослушивание

- **WHEN** у выпуска 7 есть аудио, на странице `/episodes` нажата кнопка «слушать» выпуска 7
- **THEN** воспроизведение запускается в едином плеере без перехода на страницу выпуска; размер файла в строке архива не показан

#### Scenario: Быстрое скачивание

- **WHEN** у выпуска 7 есть аудио, активирована ссылка быстрого скачивания из строки выпуска 7
- **THEN** отдаётся аудиофайл выпуска, ссылка содержит атрибут скачивания

#### Scenario: Пометки цифр

- **WHEN** выпуск с аудио длительностью 31:12 и счётчиком 42 отображается в архиве
- **THEN** длительность помечена иконкой часов, счётчик — иконкой с доступной подписью, что это прослушивания и просмотры

#### Scenario: Выпуск без аудио

- **WHEN** выпуск 5 имеет только видео, запрошен `GET /episodes`
- **THEN** строка выпуска 5 не содержит кнопок «слушать» и «скачать», но ссылается на свою страницу выпуска

### Requirement: Страница содержит Open Graph-метаданные

Страницы `GET /`, `GET /episodes` и `GET /episodes/{номер}` MUST содержать Open Graph-теги для корректного превью при расшаривании: `og:title` (название канала для лендинга и архива, заголовок выпуска для страницы выпуска), `og:description` (описание канала или описание выпуска), `og:type` = `website` для лендинга и архива и `article` для страницы выпуска, `og:url` (канонический абсолютный URL страницы) и `og:image` — абсолютный URL обложки выпуска, когда она задана, иначе обложки канала, когда она задана. Все значения MUST быть экранированы как HTML-атрибуты.

#### Scenario: Превью для мессенджера

- **WHEN** в `podcast.yaml` заданы название, описание и обложка, запрошен `GET /`
- **THEN** HTML содержит `og:title` с названием канала, `og:description` с описанием, `og:type` = `website`, `og:url` с базовым URL и `og:image` с абсолютным URL обложки канала

#### Scenario: Превью выпуска

- **WHEN** эпизод 7 имеет заголовок и описание, запрошен `GET /episodes/7`
- **THEN** HTML содержит `og:title` с заголовком выпуска, `og:description` с описанием выпуска, `og:type` = `article` и `og:url` с абсолютным URL страницы выпуска

#### Scenario: Превью выпуска с обложкой

- **WHEN** у эпизода 7 задана обложка, у эпизода 6 — нет, запрошены `GET /episodes/7` и `GET /episodes/6`
- **THEN** страница эпизода 7 содержит `og:image` с абсолютным URL обложки выпуска 7; страница эпизода 6 — `og:image` с обложкой канала, когда она задана, и без `og:image`, когда не задана

#### Scenario: Обложка не задана

- **WHEN** в `podcast.yaml` поле `image` пусто, запрошен `GET /`
- **THEN** HTML содержит `og:title`, `og:description`, `og:type` и `og:url`, а тег `og:image` отсутствует

### Requirement: JSON API отдаёт машинный список эпизодов

`GET /api/episodes` MUST возвращать JSON-массив эпизодов от новых к старым с полями: номер, заголовок, описание как markdown-исходник, дата публикации, ведущий и гости (строка и список строк; пустая строка и пустой список, когда не заданы), ссылка на YouTube (пустая строка, когда не задана), абсолютный канонический URL обложки (`cover`, пустая строка, когда обложки нет), доступные носители (kind, абсолютный канонический URL с именем файла, размер в байтах, длительность), счётчики скачиваний раздельно по audio и video и их сумма, счётчик прослушиваний, число просмотров YouTube (`youtube_views`, 0 когда неизвестно) и главы (`chapters`: массив объектов `{start, title}`, пустой массив когда глав нет).

#### Scenario: Программный доступ к списку

- **WHEN** запрошен `GET /api/episodes`
- **THEN** ответ 200, Content-Type `application/json`, массив упорядочен от нового к старому, каждый элемент содержит перечисленные поля, включая ведущего, гостей, именованные URL носителей, разбивку скачиваний по носителям, сумму, ссылку на YouTube, просмотры YouTube и главы

#### Scenario: Участники в API

- **WHEN** эпизод 45 имеет `host: Сергей Удалов` и `guests: [Мила Шведова]`, у эпизода 6 поля не заданы, запрошен `GET /api/episodes`
- **THEN** у элемента 45 `host` = «Сергей Удалов» и `guests` = [«Мила Шведова»], у элемента 6 `host` — пустая строка и `guests` — пустой список

#### Scenario: YouTube-ссылка в API

- **WHEN** у эпизода 7 задана YouTube-ссылка, у эпизода 6 — нет, запрошен `GET /api/episodes`
- **THEN** у элемента 7 поле `youtube` содержит заданный URL, у элемента 6 — пустую строку

#### Scenario: Обложка в API

- **WHEN** у эпизода 7 задана обложка, у эпизода 6 — нет, запрошен `GET /api/episodes`
- **THEN** у элемента 7 поле `cover` содержит абсолютный URL обложки, у элемента 6 — пустую строку

#### Scenario: YouTube-метрики в API

- **WHEN** у эпизода 7 известны 100 просмотров YouTube и две главы, запрошен `GET /api/episodes`
- **THEN** у элемента 7 `youtube_views` = 100, `chapters` содержит две записи с полями `start` и `title`; у эпизода без глав `chapters` — пустой массив

#### Scenario: Описание в API остаётся markdown-исходником

- **WHEN** описание эпизода 7 содержит `**важно**`, запрошен `GET /api/episodes`
- **THEN** поле `description` содержит исходный markdown-текст, HTML-разметка в нём не выводится

### Requirement: Плеер объявляет метаданные в Media Session

При воспроизведении плеер MUST публиковать в Media Session API название выпуска, название канала и обложку — обложку выпуска, когда она задана, иначе обложку канала, — а также обрабатывать системные действия play, pause, перемотки назад и вперёд на 15 секунд. Если API недоступен, воспроизведение MUST работать без ошибок.

#### Scenario: Метаданные для локскрина

- **WHEN** начато воспроизведение выпуска 7 на устройстве с Media Session API
- **THEN** метаданные содержат заголовок выпуска, название канала и абсолютный URL обложки (выпуска, когда задана, иначе канала)

#### Scenario: Системная перемотка

- **WHEN** пользователь нажал «вперёд» в системном интерфейсе
- **THEN** воспроизведение перематывается на 15 секунд вперёд

### Requirement: Страницы содержат поисковую разметку

Каждая HTML-страница MUST содержать уникальный `<title>`, meta description, абсолютный `<link rel="canonical">` и RSS autodiscovery. Лендинг MUST содержать JSON-LD `PodcastSeries` с названием, описанием, URL и обложкой канала; страница выпуска — JSON-LD `PodcastEpisode` с заголовком, датой публикации, длительностью аудио, принадлежностью сериалу и обложкой (`image`: обложка выпуска, когда задана, иначе обложка канала, когда она задана). Все значения MUST быть экранированы как HTML.

#### Scenario: Уникальный заголовок выпуска

- **WHEN** эпизод 7 имеет заголовок «Аким Губанов», запрошен `GET /episodes/7`
- **THEN** `<title>` содержит заголовок выпуска, canonical указывает на абсолютный `/episodes/7`, meta description содержит описание выпуска

#### Scenario: JSON-LD выпуска

- **WHEN** запрошен `GET /episodes/7`
- **THEN** страница содержит валидный JSON-LD `PodcastEpisode` с датой, длительностью и ссылкой на сериал

#### Scenario: JSON-LD выпуска с обложкой

- **WHEN** у эпизода 7 задана обложка, запрошен `GET /episodes/7`
- **THEN** JSON-LD содержит `image` с абсолютным URL обложки выпуска

#### Scenario: JSON-LD лендинга

- **WHEN** запрошен `GET /`
- **THEN** страница содержит валидный JSON-LD `PodcastSeries` с названием, описанием, URL и обложкой канала
