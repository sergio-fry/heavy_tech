# Spec Delta: episode-publishing

## ADDED Requirements

### Requirement: Meta описывает обложку выпуска

`episode.yaml` MAY содержать опциональное поле `cover` — имя файла-картинки в той же папке эпизода. Поддерживаемые расширения: `.jpg`, `.jpeg`, `.png`, `.webp` (регистр расширения не важен). Значение MUST быть YAML-строкой (null и отсутствие равны «обложки нет»); иначе — ошибка синхронизации. Файл обложки MUST существовать в папке эпизода, быть обычным файлом и иметь поддерживаемое расширение; иначе — ошибка синхронизации. Обложка, заданная в meta, MUST NOT считаться «лишним файлом». Индекс MUST хранить путь к файлу обложки эпизода; путь в индексе меняется при рескане, если файл обложки добавлен, удалён или заменён другим файлом.

#### Scenario: Обложка попадает в индекс

- **WHEN** в папке эпизода 7 есть `oblozhka.jpg`, `episode.yaml` содержит `cover: oblozhka.jpg`, выполнен рескан
- **THEN** индекс хранит для эпизода 7 путь к `oblozhka.jpg`

#### Scenario: Обложка необязательна

- **WHEN** в `episode.yaml` эпизода 6 нет поля `cover` (или оно пустое), выполнен рескан
- **THEN** эпизод публикуется как обычно, обложка считается не заданной

#### Scenario: Некорректный тип — ошибка синхронизации

- **WHEN** `cover:` в `episode.yaml` — число вместо строки, выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации

#### Scenario: Неподдерживаемое расширение — ошибка синхронизации

- **WHEN** `cover: oblozhka.tiff`, выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации

#### Scenario: Файл не существует — ошибка синхронизации

- **WHEN** `cover: net.jpg`, файла `net.jpg` в папке эпизода нет, выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации

#### Scenario: Обложка не лишний файл

- **WHEN** в папке эпизода 7 лежат `episode.yaml`, аудио и `oblozhka.jpg`, и `cover: oblozhka.jpg` задан
- **THEN** рескан проходит без ошибки «файл не упомянут»
