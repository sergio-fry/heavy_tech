# Spec Delta: episode-publishing

## ADDED Requirements

### Requirement: Описание выпуска хранится в markdown-файле

В папке эпизода MAY лежать необязательный файл `description.md` с описанием выпуска в markdown. Если файл есть, его содержимое MUST быть источником описания и MUST иметь приоритет над полем `description:` в `episode.yaml`; при отсутствии файла MUST использоваться `description:` (тоже как markdown-исходник). Пустое описание допустимо. Файл `description.md` MUST не считаться неупомянутым в meta и MAY изменяться без правки `episode.yaml`.

#### Scenario: Новый эпизод с markdown-описанием

- **WHEN** в папке `7` создан `description.md` с markdown-текстом, выполнен рескан
- **THEN** эпизод 7 проиндексирован с описанием из файла, рескан не сообщает о лишнем файле

#### Scenario: Файл приоритетнее поля в meta

- **WHEN** в `episode.yaml` задан `description: Старое`, а рядом лежит `description.md` с другим текстом, выполнен рескан
- **THEN** индекс и публичные представления используют текст из `description.md`

#### Scenario: Фолбэк на описание из meta

- **WHEN** `description.md` отсутствует, а `episode.yaml` содержит `description: О чём выпуск`, выполнен рескан
- **THEN** эпизод публикуется с описанием из meta

#### Scenario: Правка description.md обновляет индекс

- **WHEN** содержимое `description.md` эпизода 7 изменено и выполнен рескан
- **THEN** индекс содержит новое описание, рескан сообщает об одном обновлённом эпизоде

#### Scenario: Описание необязательно

- **WHEN** в папке эпизода нет ни `description.md`, ни `description:` в meta, выполнен рескан
- **THEN** эпизод публикуется без описания, ошибки нет

### Requirement: Эпизод может ссылаться на YouTube-версию

Необязательное поле `youtube:` в `episode.yaml` задаёт ссылку на видеоверсию выпуска. Значение MUST быть абсолютным URL со схемой `http` или `https`; иное значение MUST приводить к ошибке синхронизации. Отсутствующее или пустое поле допустимо и означает, что ссылки нет. Существование ролика сканер не проверяет.

#### Scenario: Валидная ссылка попадает в индекс

- **WHEN** `episode.yaml` эпизода 7 содержит `youtube: https://youtu.be/abc123`, выполнен рескан
- **THEN** эпизод 7 сохранён в индексе со ссылкой на YouTube

#### Scenario: Некорректная ссылка — ошибка синхронизации

- **WHEN** `episode.yaml` содержит `youtube: youtu.be/abc123` или `javascript:alert(1)`, выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации, индекс остаётся в последнем консистентном состоянии

#### Scenario: Ссылка необязательна

- **WHEN** в `episode.yaml` нет поля `youtube:`, выполнен рескан
- **THEN** эпизод публикуется без YouTube-ссылки, ошибки нет

## MODIFIED Requirements

### Requirement: Носители ограничены и классифицируются по расширению

У эпизода MUST быть не более одного аудио- и одного видеоносителя: секции `audio:` и `video:` в meta. Классификация — по расширению: `.mp3`/`.aac`/`.m4a` — аудио, `.mp4`/`.mov`/`.mkv`/`.webm` — видео; файл в секции MUST иметь расширение своего kind. Характеристики (duration, bitrate, resolution) информационные — сканер проверяет только существование файлов. Не упомянутый в meta файл (кроме dot-файлов и `description.md`) — ошибка синхронизации; dot-файлы игнорируются.

#### Scenario: Аудио и видео одного выпуска

- **WHEN** папка `7` содержит `audio:` на `zapis.m4a` и `video:` на `efir.mp4`, оба файла существуют, выполнен рескан
- **THEN** эпизод 7 проиндексирован с двумя носителями: аудио MIME `audio/x-m4a`, видео — по расширению `.mp4`

#### Scenario: Аудио-файл в video-секции — ошибка

- **WHEN** `video:` ссылается на `zapis.m4a` (аудио-расширение), выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации

#### Scenario: Неупомянутый файл — ошибка

- **WHEN** в папке эпизода лежит лишний `staraya-zapis.mp3`, не указанный в meta, выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации

#### Scenario: Dot-файл игнорируется

- **WHEN** в папке эпизода лежит `.zapis.m4a.gSNpVJ` (временный файл копирования), выполнен рескан
- **THEN** эпизод публикуется без ошибок

#### Scenario: description.md не считается лишним файлом

- **WHEN** в папке эпизода лежит `description.md`, не упомянутый в meta, выполнен рескан
- **THEN** рескан завершается успешно, описание выпуска берётся из этого файла
