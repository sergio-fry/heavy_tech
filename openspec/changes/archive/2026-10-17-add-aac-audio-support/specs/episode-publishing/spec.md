# Spec Delta: episode-publishing

## MODIFIED Requirements

### Requirement: Эпизод обнаруживается по имени файла

Система MUST распознавать аудиофайл эпизода по имени вида `YYYY-MM-DD-slug.<ext>`: `YYYY-MM-DD` задаёт дату публикации, `slug` — стабильный идентификатор эпизода. Поддерживаемые расширения и MIME-типы: `.mp3` → `audio/mpeg`, `.aac` → `audio/aac`, `.m4a` → `audio/x-m4a`. MIME-тип эпизода MUST определяться расширением файла и сохраняться в индексе. Файлы, не соответствующие шаблону имени или имеющие другое расширение, MUST игнорироваться.

#### Scenario: Новый файл попадает в индекс

- **WHEN** в папку подкастов помещён файл `2026-10-01-pervyy-vypusk.mp3` и выполнен рескан
- **THEN** эпизод со slug `pervyy-vypusk` и датой публикации 2026-10-01 появляется в индексе и доступен через сайт, фид и API

#### Scenario: Файл с неверным именем игнорируется

- **WHEN** в папке лежит файл `my-episode.mp3` (без даты) и выполнен рескан
- **THEN** эпизод не создаётся, сервис продолжает работать

#### Scenario: AAC-файл попадает в индекс с корректным MIME

- **WHEN** в папку подкастов помещён файл `2026-10-02-vtoroy.aac` и выполнен рескан
- **THEN** появляется эпизод со slug `vtoroy`, датой 2026-10-02 и MIME `audio/aac`

#### Scenario: M4A-файл попадает в индекс с корректным MIME

- **WHEN** в папку подкастов помещён файл `2026-10-03-tretiy.m4a` и выполнен рескан
- **THEN** появляется эпизод со slug `tretiy`, датой 2026-10-03 и MIME `audio/x-m4a`

#### Scenario: Неподдерживаемое расширение игнорируется

- **WHEN** в папке лежат файлы `2026-10-04-zapis.wav` и `2026-10-05-konpekt.flac` и выполнен рескан
- **THEN** эпизоды не создаются, сервис продолжает работать

#### Scenario: Дубликат слага у разных расширений — ошибка синхронизации

- **WHEN** в папке одновременно лежат `2026-10-01-duet.mp3` и `2026-10-01-duet.m4a` и выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации папки, индекс остаётся в последнем консистентном состоянии
