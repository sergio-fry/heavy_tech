# Design

## Context

См. `proposal.md` — мотивация упрощения архива. Сейчас строка архива — это `<a class="row">` целиком (`web/episodes.html`), фильтры живут в шапке страницы и в `app.js` (блок «поиск и фильтры архива»), данные для них — `data-year`/`data-guests`/`data-video`/`data-search` на строке и поля `Years`/`SearchText` в `pages.go`. Единый плеер уже умеет запускаться с любой страницы по кнопке `.js-play` с атрибутами `data-episode`, `data-src`, `data-title`, `data-duration` (так работают «Слушать последний выпуск» на лендинге и плеер страницы выпуска), включая мини-панель и продолжение с сохранённой позиции.

## Goals / Non-Goals

- Клик по строке архива ведёт на страницу выпуска — поведение сохраняется.
- Кнопки «слушать» и «скачать» работают прямо из строки, не ломая переход по строке и не требуя перезагрузки страницы.
- Числа длительности и счётчика читаются без контекста.
- Удаляем мёртвый код фильтров (JS, CSS, Go-поля), а не комментируем.
- Non-goal: не трогаем страницу выпуска и лендинг (там свои подписи и полный блок скачиваний с размерами); не вводим иконочный шрифт; не меняем `/api/episodes` и фиды; видео-скачивание в строке архива не добавляем (кнопка «скачать» — аудио; полный набор носителей остаётся на странице выпуска).

## Decisions

### 1. Строка архива: div-контейнер + «растянутая» ссылка вместо `<a>` целиком

Кнопка и ссылка скачивания внутри `<a>` — невалидный HTML (интерактивный элемент в интерактивном), клики по кнопкам конфликтовали бы с переходом.

Решение: строка становится `<div class="row">`, внутри которого номер и текст обёрнуты в `<a class="row-link">` с CSS-приёмом stretched link (ссылка растягивается на всю строку через `::after`/`position`, кнопки лежат поверх с `position: relative; z-index`). Клик мимо кнопок — переход на страницу выпуска; кнопки перехватывают клик.

Альтернатива — обрабатывать клики по строке в JS и делать `location.href`: ломает работу без JavaScript и middle-click/«открыть в новой вкладке». Отклонена.

### 2. «Слушать» — переиспользование существующего контракта `.js-play`

Кнопка в строке получает те же атрибуты `data-episode/data-src/data-title/data-duration`, что и кнопки на лендинге/странице выпуска. В глобальном обработчике кликов `app.js` добавляется `event.preventDefault()` для `.js-play` внутри строк (сейчас кнопки `.js-play` не вложены в ссылки, поэтому preventDefault не нужен; в архиве без него клик по кнопке уводил бы на страницу выпуска). Повторный клик по играющему выпуску — пауза, как и сейчас (`setIcons` синхронизирует глифы).

### 3. «Скачать» — прямая ссылка на именованный аудио-URL с `download`

`<a class="row-dl" href="{AudioURL}" download>` без текста размера. Именованный URL (`/audio/{номер}/{имя}.{ext}`) уже отдаётся полем `AudioURL` в `episodeItem`; атрибут `download` на same-origin даёт сохранение файла без страницы выпуска. Клик не требует JS.

Альтернатива — кнопка со счётчиком скачивания через API: усложнение без пользы, скачивание и так считается по HTTP-запросам.

### 4. Иконки — юникод-глифы, как в остальном интерфейсе

Проект не тянет иконочных шрифтов: плеер уже использует `▶`/`❚❚`. Длительность помечаем глифом часов (`◷`), счётчик — глифом прослушивания (`▶` мелким кеглем или наушники `🎧`; выбираем `🎧` — однозначнее читается как «прослушано», при этом `aria-label` остаётся «Прослушиваний и просмотров: N», как сейчас). Глифы идут с `aria-hidden="true"`, смысл несёт доступная подпись. Итоговый набор глифов фиксируется на имплементации по визуальной читаемости; контракт спеки — иконка + доступная подпись, не конкретный символ.

### 5. Чистка данных фильтров

- `pages.go`: удалить `SearchText` из `episodeItem` (использовался только атрибутом `data-search`) и сборку `Years` для страницы архива; поля `Year`, `HasVideo`, `Guests` остаются — они нужны разметке/`API`.
- `app.js`: удалить весь блок «поиск и фильтры архива» и заглушку `#no-results`.
- `style.css`: удалить правила `.filters*`, добавить стили `.row-link`, `.row-actions`, глифы.

## Risks / Trade-offs

- [Глиф `🎧` отображается эмодзи-стилем в части браузеров и выбивается из текстовой строки] → фиксируется на имплементации: либо `text-decoration`-нейтральный глиф (`◷`/`▶`), либо лёгкая правка CSS (font-family); контракт («иконка + подпись») не зависит от символа.
- [Растянутая ссылка увеличивает кликабельную зону до всей строки — случайные клики по краю строки ведут на страницу выпуска] → это текущее поведение (`<a>` на всю строку), регресса нет.
- [Рост правого края строки: кнопки + счётчик могут тесниться на узких экранах] → на мобильных кнопки остаются иконками без текста (текст только `aria-label`), счётчик переносится под мету при нехватке места.
- [Через полгода выпусков станет много и поиск захочется вернуть] → код в git-истории и в архиве спецификаций (`2026-10-22-improve-listener-experience`); возврат — отдельный change.

## Migration Plan

Единый выкат, без миграций данных: правки только в шаблоне/JS/CSS/данных страницы и тестах. Откат — revert коммита. Деплой по обычной схеме (`deploy` через infra-репо), проверка на `heavytech.dev.apps.udalovs.ru`.
