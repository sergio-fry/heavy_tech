# Spec Delta: podcast-serving

## MODIFIED Requirements

### Requirement: Сайт показывает список эпизодов с плеером

`GET /` MUST возвращать HTML-страницу со списком эпизодов от новых к старым: номер выпуска, дата словами по-русски, заголовок, участники выпуска, отрендеренное markdown-описание, единый счётчик потребления выпуска (сумма скачиваний аудио и видео и прослушиваний), встроенный аудиоплеер для эпизодов с аудио и явные ссылки «скачать» на каждый доступный носитель с размером файла, именем файла в URL и атрибутом `download`. Участники выпуска MUST выводиться строками «Ведущий: …» и «Гости: …» (гости — в сохранённом порядке, через запятую); каждая строка — только когда соответствующее поле непусто. Если у эпизода задана YouTube-ссылка, карточка MUST содержать действие «Смотреть на YouTube» с этой ссылкой; при отсутствии ссылки действия нет. Страница MUST содержать герой-блок канала: название, описание и обложку из `podcast.yaml` (когда обложка задана), действие «слушать последний выпуск» (запускает воспроизведение самого нового эпизода с аудио) и действие «скопировать ссылку на RSS». Плеер эпизода MUST иметь кнопку play/pause и прогресс-бар с перемоткой по клику; при старте воспроизведения плеер отправляет `POST /track/play`. Нативный `<audio controls>` не используется. Для видео ссылки на скачивание есть, веб-плеер видео не отображается. Пустой список MUST отображаться осмысленной заглушкой.

#### Scenario: Эпизод виден на сайте

- **WHEN** в индексе есть эпизод 7 «Аким Губанов» (дата 2026-10-15, аудио и видео, 120 скачиваний аудио, 30 видео, 5 прослушиваний), запрошен `GET /`
- **THEN** HTML содержит номер выпуска, дату словами, заголовок, отрендеренное описание, плеер с `data-episode="7"`, ссылки «скачать» на именованные URL `/audio/7/007-<slug>.<ext>` и `/video/7/007-<slug>.<ext>` с размерами и атрибутом `download`, а также единый счётчик со значением 155

#### Scenario: Участники выпуска на карточке

- **WHEN** эпизод 45 имеет `host: Сергей Удалов` и `guests: [Мила Шведова, Дмитрий Копров]`, запрошен `GET /`
- **THEN** карточка эпизода 45 содержит строки «Ведущий: Сергей Удалов» и «Гости: Мила Шведова, Дмитрий Копров»

#### Scenario: Без участников линии не рисуются

- **WHEN** у эпизода 5 поля `host` и `guests` не заданы, запрошен `GET /`
- **THEN** карточка эпизода 5 не содержит строк «Ведущий:» и «Гости:»

#### Scenario: YouTube-ссылка выводится в карточке

- **WHEN** у эпизода 7 в meta задана YouTube-ссылка, запрошен `GET /`
- **THEN** карточка эпизода 7 содержит действие «Смотреть на YouTube» с этой ссылкой

#### Scenario: Без YouTube-ссылки действия нет

- **WHEN** у эпизода 7 нет YouTube-ссылки, запрошен `GET /`
- **THEN** карточка эпизода 7 не содержит действия «Смотреть на YouTube»

#### Scenario: Видео-выпуск без аудио

- **WHEN** эпизод 5 имеет только видеоноситель, запрошен `GET /`
- **THEN** карточка эпизода 5 содержит ссылку на скачивание видео с именем файла, аудиоплеер для него не отображается

#### Scenario: Герой-блок и копирование RSS

- **WHEN** в `podcast.yaml` заданы название, описание и обложка, запрошен `GET /`
- **THEN** HTML содержит герой-блок с названием, описанием и обложкой канала, кнопку «слушать последний выпуск» с номером самого нового эпизода с аудио и элемент копирования RSS-ссылки (абсолютный URL `/feed.xml`)

#### Scenario: Пустой подкаст

- **WHEN** эпизодов нет, запрошен `GET /`
- **THEN** страница отображает заглушку «Выпуски скоро появятся» и ссылку на фид

### Requirement: JSON API отдаёт машинный список эпизодов

`GET /api/episodes` MUST возвращать JSON-массив эпизодов от новых к старым с полями: номер, заголовок, описание как markdown-исходник, дата публикации, ведущий и гости (строка и список строк; пустая строка и пустой список, когда не заданы), ссылка на YouTube (пустая строка, когда не задана), доступные носители (kind, абсолютный канонический URL с именем файла, размер в байтах, длительность), счётчики скачиваний раздельно по audio и video и их сумма, счётчик прослушиваний.

#### Scenario: Программный доступ к списку

- **WHEN** запрошен `GET /api/episodes`
- **THEN** ответ 200, Content-Type `application/json`, массив упорядочен от нового к старому, каждый элемент содержит перечисленные поля, включая ведущего, гостей, именованные URL носителей, разбивку скачиваний по носителям, сумму и ссылку на YouTube

#### Scenario: Участники в API

- **WHEN** эпизод 45 имеет `host: Сергей Удалов` и `guests: [Мила Шведова]`, у эпизода 6 поля не заданы, запрошен `GET /api/episodes`
- **THEN** у элемента 45 `host` = «Сергей Удалов» и `guests` = [«Мила Шведова»], у элемента 6 `host` — пустая строка и `guests` — пустой список

#### Scenario: YouTube-ссылка в API

- **WHEN** у эпизода 7 задана YouTube-ссылка, у эпизода 6 — нет, запрошен `GET /api/episodes`
- **THEN** у элемента 7 поле `youtube` содержит заданный URL, у элемента 6 — пустую строку

#### Scenario: Описание в API остаётся markdown-исходником

- **WHEN** описание эпизода 7 содержит `**важно**`, запрошен `GET /api/episodes`
- **THEN** поле `description` содержит исходный markdown-текст, HTML-разметка в нём не выводится
