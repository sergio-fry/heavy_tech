# Spec Delta: episode-publishing

## ADDED Requirements

### Requirement: Meta описывает участников выпуска

`episode.yaml` MAY содержать опциональные поля участников: `host` (строка — ведущий выпуска) и `guests` (список строк — гости в порядке вывода). Значения — только человекочитаемые имена; пустая строка и пустой список равны отсутствию. Система MUST сохранять их в индексе как есть (после трима пробелов), без подстановок по умолчанию и без вывода из имён файлов; порядок гостей MUST сохраняться в индексе. Некорректный тип значения (не строка / не список строк) — ошибка синхронизации.

#### Scenario: Участники попадают в индекс

- **WHEN** `episode.yaml` эпизода 45 содержит `host: Сергей Удалов` и `guests: [Мила Шведова, Дмитрий Копров]`, выполнен рескан
- **THEN** индекс хранит для эпизода 45 ведущего и двух гостей в заданном порядке

#### Scenario: Поля необязательны

- **WHEN** в `episode.yaml` эпизода 7 нет полей `host` и `guests`, выполнен рескан
- **THEN** эпизод публикуется как обычно, участники считаются не указанными

#### Scenario: Некорректный тип — ошибка синхронизации

- **WHEN** `guests:` в `episode.yaml` — строка вместо списка, выполнен рескан
- **THEN** рескан завершается ошибкой синхронизации
