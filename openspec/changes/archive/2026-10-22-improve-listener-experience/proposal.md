# Proposal

## Why

Сайт рассчитан на одного слушателя с одним сценарием: одна страница со всеми 49 выпусками, шоу-ноуты всегда развёрнуты, плеер уезжает за экран при скролле, а 37 карточек показывают «0». У выпуска нет собственного URL, поэтому ссылку в мессенджере нельзя расшарить с превью, поисковику нечего индексировать, а постоянный слушатель не может вернуться к месту, где остановился. При этом видео смотрят на YouTube, но эти просмотры не попадают в счётчики, а таймкоды для навигации по выпуску есть только там.

## What Changes

- **Лендинг на `/` для первого визита и поиска**: промо-текст канала из нового `about.md`, последние выпуски, подборка «с чего начать», подписка на платформы. **BREAKING**: полный список выпусков переезжает с `/` на `/episodes`.
- **Архив `/episodes`**: компактные строки вместо карточек с полными ноутами, поиск по заголовку/описанию/гостю и фильтры по году, наличию гостя и видео.
- **Страницы выпусков `/episodes/{номер}`**: полные шоу-ноуты, плеер, главы, скачивания, шеринг, переходы к соседним выпускам.
- **Один постоянный плеер вместо плеера в каждой карточке**: закреплённая мини-панель при скролле, продолжение с сохранённой позиции, скорость воспроизведения, Media Session API, клавиатурная и тач-доступная перемотка.
- **Главы из YouTube**: таймкоды берутся из описания ролика, хранятся в индексе и показываются отдельным разделом плеера, а не внутри краткого описания.
- **Счётчики YouTube**: число просмотров периодически подтягивается через YouTube Data API по ключу из конфигурации и суммируется с локальными скачиваниями и прослушиваниями.
- **Гигиена выдачи**: единый счётчик не показывается, пока он равен нулю; номер выпуска не дублируется; участники оформлены как метаданные; скачивание уходит на второй план.
- **SEO**: уникальные title/description/canonical/OG для страниц, JSON-LD `PodcastSeries`/`PodcastEpisode`, `sitemap.xml`, `robots.txt`, RSS autodiscovery.
- **Подписка вместо «скопировать RSS»**: кнопки платформ из `podcast.yaml`, копирование ссылки остаётся запасным вариантом.

## Capabilities

### New Capabilities

- `youtube-sync`: интеграция с YouTube Data API — извлечение video id из ссылки выпуска, главы из описания ролика, периодическое обновление просмотров, хранение и деградация без ключа.

### Modified Capabilities

- `podcast-serving`: лендинг, архив, страницы выпусков, единый плеер с главами и продолжением, SEO-метаданные и sitemap, подписка, отображение счётчиков.
- `audience-metrics`: единый счётчик потребления включает просмотры YouTube; API отдаёт просмотры отдельным полем; нулевой счётчик не выводится на сайте.
- `episode-publishing`: новые необязательные поля `podcast.yaml` (`tagline`, `links`, `start_here`), лендинг-файл `about.md`, правила их валидации.

## Impact

- Роуты: `/` меняет содержание, добавляются `/episodes`, `/episodes/{номер}`, `/sitemap.xml`, `/robots.txt`.
- Код: `handlers.go`, `web/index.html` → несколько шаблонов, новый пакет/файл синхронизации YouTube, `config.go`, `store.go`, миграция `0005`.
- Конфигурация: `YOUTUBE_API_KEY` (обязателен только для YouTube-функций), новые поля `podcast.yaml`, новый `about.md` в папке подкастов.
- Данные: новая таблица метаданных YouTube с каскадным удалением по эпизоду; существующие события метрик не меняются.
- Фиды и медиа-URL не меняются: guid и enclosure остаются прежними.
- Внешняя зависимость: YouTube Data API v3 (квота расходуется на `videos.list`, батчами до 50 id).
- Тесты: обработчики страниц и sitemap, парсер глав, синхронизация просмотров, конфигурация канала, миграция.
