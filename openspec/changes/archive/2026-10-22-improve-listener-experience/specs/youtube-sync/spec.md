# Spec Delta

## Purpose

Держит метаданные YouTube-версий выпусков (главы и число просмотров) актуальными, не блокируя публикацию и работу сайта при недоступности внешнего API.

## ADDED Requirements

### Requirement: YouTube-интеграция необязательна

Сервис MUST запускаться и полностью обслуживать сайт, фиды и медиа без ключа YouTube Data API. Ключ MUST читаться из конфигурации и MUST NOT логироваться, отдаваться в ответах или попадать в репозиторий. При отсутствии ключа синхронизация YouTube MUST быть отключена с одной записью в лог; остальные функции работают как обычно.

#### Scenario: Запуск без ключа

- **WHEN** сервис запущен без `YOUTUBE_API_KEY`
- **THEN** сайт, фиды, API и медиа работают, в лог записано одно сообщение об отключённой синхронизации, страницы не содержат ошибок

#### Scenario: Ключ не утекает

- **WHEN** ключ задан, запрошены `GET /`, `/api/episodes`, `/sitemap.xml` и логи сервиса
- **THEN** значение ключа отсутствует в ответах и в логах

### Requirement: Идентификатор ролика извлекается из ссылки выпуска

Из поля `youtube` эпизода MUST извлекаться идентификатор ролика для ссылок вида `youtu.be/{id}`, `youtube.com/watch?v={id}`, `youtube.com/shorts/{id}`, `youtube.com/embed/{id}` и `youtube.com/live/{id}`, в том числе с дополнительными query-параметрами. Ссылка, из которой идентификатор не извлекается, MUST NOT ломать публикацию: эпизод публикуется как обычно, YouTube-синхронизация для него пропускается с предупреждением в лог.

#### Scenario: Короткая ссылка

- **WHEN** `episode.yaml` содержит `youtube: https://youtu.be/abc123?t=30`, выполнен рескан
- **THEN** для эпизода сохранён идентификатор `abc123`

#### Scenario: Ссылка watch с параметрами

- **WHEN** `episode.yaml` содержит `youtube: https://www.youtube.com/watch?v=abc123&list=PL1`, выполнен рескан
- **THEN** для эпизода сохранён идентификатор `abc123`

#### Scenario: Нераспознанная ссылка не блокирует выпуск

- **WHEN** `episode.yaml` содержит `youtube: https://example.com/video/abc123`, выполнен рескан
- **THEN** эпизод опубликован, YouTube-синхронизация пропущена, в лог записано предупреждение

#### Scenario: Ссылки нет

- **WHEN** у эпизода не задано поле `youtube`, выполнен рескан
- **THEN** эпизод опубликован, YouTube-синхронизация для него не выполняется

### Requirement: Главы извлекаются из описания ролика

Главы MUST извлекаться из описания видео, полученного через YouTube Data API: не менее трёх строк вида `[ч:]мм:сс` с непустым названием, при этом первая глава MUST начинаться с `0:00`. Главы MUST храниться упорядоченным списком пар «начало в секундах — название» в порядке исходного описания. Если описание не соответствует этим условиям, глав у эпизода нет; ошибки публикации это не вызывает.

#### Scenario: Валидный список глав

- **WHEN** описание ролика содержит строки `0:00 Вступление`, `12:30 Основная часть`, `1:02:10 Итоги`
- **THEN** у эпизода сохранены три главы с началами 0, 750 и 3730 секунд и соответствующими названиями

#### Scenario: Слишком короткий список

- **WHEN** описание содержит только `0:00 Вступление` и `12:30 Основная часть`
- **THEN** глав у эпизода нет

#### Scenario: Первая глава не с нуля

- **WHEN** описание содержит `0:10 Вступление`, `12:30 Основная часть`, `1:02:10 Итоги`
- **THEN** глав у эпизода нет

### Requirement: Просмотры YouTube обновляются периодически

Число просмотров ролика MUST запрашиваться через YouTube Data API и сохраняться вместе со временем получения. Обновление MUST выполняться при старте сервиса и далее периодически, не чаще одного раза в 6 часов на эпизод, с группировкой до 50 идентификаторов в одном запросе. Ошибка или недоступность внешнего API MUST сохранять последнее известное значение и MUST NOT влиять на отдачу страниц, фидов и медиа.

#### Scenario: Успешное обновление

- **WHEN** YouTube вернул `viewCount = 12345` для эпизода 7
- **THEN** для эпизода 7 сохранены просмотры 12345 и время получения

#### Scenario: Ошибка внешнего API

- **WHEN** для эпизода 7 ранее сохранено 12345 просмотров, а очередной запрос к YouTube завершился ошибкой
- **THEN** сохранённое значение осталось 12345, страницы и фиды отдаются без ошибок

#### Scenario: Повторный запрос не чаще окна обновления

- **WHEN** просмотры эпизода 7 обновлены менее 6 часов назад и запущен новый цикл синхронизации
- **THEN** запрос к YouTube по эпизоду 7 не выполняется

### Requirement: Метаданные YouTube удаляются вместе с эпизодом

Сохранённые главы и просмотры YouTube MUST храниться в SQLite отдельно от индекса эпизодов и MUST удаляться при исчезновении эпизода из папки. После потери базы метаданные YouTube MUST восстанавливаться повторным запросом к API, а не из файлов папки.

#### Scenario: Эпизод удалён из папки

- **WHEN** папка эпизода 7 удалена и выполнен рескан
- **THEN** запись с главами и просмотрами эпизода 7 отсутствует в базе

#### Scenario: База потеряна

- **WHEN** SQLite-файл удалён, сервис перезапущен с ключом YouTube
- **THEN** индекс восстановлен сканированием, главы и просмотры запрошены у YouTube заново
