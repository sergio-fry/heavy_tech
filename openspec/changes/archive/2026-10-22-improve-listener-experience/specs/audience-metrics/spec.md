# Spec Delta

## MODIFIED Requirements

### Requirement: Счётчики видны на сайте и в API

Сайт MUST показывать по каждому эпизоду единый счётчик потребления — сумму скачиваний (аудио + видео), прослушиваний и просмотров YouTube (последнее известное значение; 0, когда просмотры неизвестны). Счётчик MUST NOT выводиться, пока он равен нулю. JSON API MUST сохранять раздельные агрегаты: скачивания раздельно по audio и video и их сумму, прослушивания отдельно, просмотры YouTube отдельным полем. Локальные агрегаты MUST вычисляться из сырых событий запросами, без предвычисленных счётчиков в индексе эпизодов; просмотры YouTube MUST браться из последнего сохранённого снимка.

#### Scenario: Числа согласованы

- **WHEN** у эпизода 7 три скачивания аудио, одно видео, одно прослушивание и 200 просмотров YouTube, запрошены `GET /episodes/7` и `GET /api/episodes`
- **THEN** сайт показывает единый счётчик 205, API — `downloads.audio=3`, `downloads.video=1`, `downloads.total=4`, `plays=1`, `youtube_views=200`

#### Scenario: Просмотры YouTube неизвестны

- **WHEN** у эпизода 7 нет сохранённого снимка YouTube, запрошен `GET /api/episodes`
- **THEN** `youtube_views` = 0, единый счётчик на сайте равен сумме локальных событий

#### Scenario: Нулевой счётчик не выводится

- **WHEN** у эпизода 7 нет ни скачиваний, ни прослушиваний, ни просмотров YouTube, запрошены `GET /episodes` и `GET /episodes/7`
- **THEN** счётчик потребления на сайте не отображается, вместо него ничего не выводится

#### Scenario: Объединение не меняет раздельный сбор

- **WHEN** клиент скачал аудио эпизода 7, запрошен `GET /episodes/7`
- **THEN** на сайте единый счётчик вырос на 1, в API скачивания выросли на 1, а прослушивания и просмотры YouTube не изменились
