# Spec Delta

## ADDED Requirements

### Requirement: Текст лендинга хранится в about.md

В корне папки подкастов MAY лежать `about.md` — markdown-текст лендинга. При наличии он MUST быть источником основного текста лендинга и MUST иметь приоритет над описанием канала; при отсутствии MUST использоваться описание канала. Файл MUST читаться при старте сервиса и обновляться при `POST /admin/rescan`. Рендеринг MUST использовать те же правила безопасного markdown, что и описания выпусков; сырой HTML MUST NOT исполняться.

#### Scenario: about.md задаёт текст лендинга

- **WHEN** в корне папки подкастов есть `about.md` с заголовком и абзацем, запрошен `GET /`
- **THEN** лендинг содержит отрендеренные заголовок и абзац из файла

#### Scenario: Правка about.md подхватывается ресканом

- **WHEN** текст `about.md` изменён и вызван `POST /admin/rescan`, затем запрошен `GET /`
- **THEN** лендинг содержит новый текст без перезапуска сервиса

#### Scenario: Файла нет

- **WHEN** `about.md` отсутствует, запрошен `GET /`
- **THEN** лендинг показывает описание канала из `podcast.yaml`, ошибки нет

#### Scenario: Сырой HTML не исполняется

- **WHEN** `about.md` содержит `<script>alert(1)</script>`
- **THEN** HTML лендинга не содержит исполняемого тега `script`

## MODIFIED Requirements

### Requirement: Конфигурация канала читается из podcast.yaml

В корне папки подкастов MUST читаться `podcast.yaml` с метаданными канала: название, описание, автор, e-mail, обложка, категория, explicit, ссылка. MAY содержать `tagline`, `links` (пары label/url с абсолютными http(s)-адресами) и `start_here` (номера выпусков). Некорректный тип, пустой label или не-http(s) URL MUST быть ошибкой конфигурации; номера из `start_here`, отсутствующие в индексе, MUST логироваться и пропускаться. Без файла или пустых title/description сервис MUST не стартовать.

#### Scenario: Метаданные канала применяются

- **WHEN** `podcast.yaml` задаёт название и автора канала
- **THEN** фид и сайт отображают эти название и автора

#### Scenario: Нечего публиковать без конфига

- **WHEN** сервис стартует без `podcast.yaml` в папке подкастов
- **THEN** сервис завершается с понятной ошибкой конфигурации

#### Scenario: Подписки и tagline применяются

- **WHEN** `podcast.yaml` задаёт `tagline` и `links` из двух платформ, запрошен `GET /`
- **THEN** лендинг показывает tagline и две кнопки подписки в заданном порядке

#### Scenario: Некорректная ссылка подписки

- **WHEN** `links` содержит элемент без label или с URL `javascript:alert(1)`
- **THEN** сервис не стартует с ошибкой конфигурации

#### Scenario: Неизвестный номер в подборке

- **WHEN** `start_here` содержит номер 999, которого нет в индексе, запрошен `GET /`
- **THEN** сервис работает, номер 999 пропущен с записью в лог, остальные выпуски подборки показаны
