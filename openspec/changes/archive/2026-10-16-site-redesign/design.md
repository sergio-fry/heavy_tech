# Design

## Context

Страница одна, шаблон и стили инлайновые (`web/index.html`), JS — без сборки. Контент и так приходит из стора; для нового дизайна не хватает производных данных: обложка канала, slug последнего выпуска, даты словами, URL фида (уже есть). Спека `audience-metrics` не меняется — play-бикон остаётся.

## Goals / Non-Goals

**Goals:**

- «Студийная редакционная» подача: канал узнаваем за 3 секунды, слушать — в один клик.
- Ноль внешних зависимостей: системные шрифты, инлайновый CSS/JS, SVG-фавикон дата-URI.
- Обе темы почти бесплатно: CSS-переменные + `prefers-color-scheme`.
- Красивые превью ссылок: OG-теги из `podcast.yaml`.

**Non-Goals:**

- Пер-эпизодные обложки (плитка-заглушка — CSS-градиент с номером выпуска; поле в sidecar — задел на будущее, сейчас не читаем).
- Бейджи Apple/Spotify/YouTube (канала там ещё нет), страницы эпизодов, аналитика просмотров, кастомные шрифты.

## Decisions

**D1. Темы через CSS-переменные + `prefers-color-scheme`, без переключателя.**
Светлая: фон `#faf9f7`, карточка `#ffffff` (рамка `#eceae7`), текст `#1a1a1a`, мета `#6b7280`, акцент `#d14e24`. Тёмная: фон `#0f1115`, карточка `#161a22` (рамка `#232833`), текст `#e8eaf0`, мета `#8b93a3`, акцент `#ff8a5c`. `color-scheme: light dark` — нативные контролы (если всплывут) тоже темизируются. Переключатель в UI сознательно не делаем.

**D2. Типографика: системный гротеск, без webfonts.**
Стек: `system-ui, -apple-system, "Segoe UI", Roboto, Inter, sans-serif`. Заголовки: weight 700–800, letter-spacing -0.02em, размер героя ~clamp(1.8rem, 4vw, 2.6rem). Радиусы 12–16px, тени нет (только рамки), воздух: контейнер 720px, отступы секций ≥2rem. Движение: только hover/фокус-переходы 0.15s, без анимаций ради анимаций.

**D3. Разметка страницы: три блока.**
Шапка (знак HT + название + ссылка «О канале»? нет — якорь на героя), герой (обложка 160–200px из `Channel.Image`; название, описание; две кнопки: «Слушать последний выпуск» — круглая ▶ + текст, «Скопировать RSS» — вторичная), список карточек эпизодов, футер (© год, RSS, «Go + SQLite»). Данные, которых не было: `Channel.Image` (уже в структуре Channel), slug последнего выпуска (первый элемент списка), дата словами — форматирование на бэкенде (`02.01.2006` → «2 октября 2026», `time.Format` с русскими месяцами через срез строк — руками map, без локализации-библиотеки).

**D4. Кастомный плеер: один активный инстанс.**
Каждая карточка: круглая кнопка ▶/⏸ (aria-label), полоса прогресса (div, seek по клику с учётом `getBoundingClientRect`), подписи `0:00 / 15:48`. Внутри по-прежнему `<audio>` (без `controls`, `preload="none"`, `src` на абсолютный URL — как раньше), JS-обвязка ~40 строк: toggle play/pause, `timeupdate` → ширина полосы и подпись, `ended` → сброс. Одновременно играет максимум один (остальные ставим на паузу). Play-старт триггерит существующий бикон в `/track/play` — код переиспользуется, события `play` у `audio` достаточно. Кнопка «слушать последний» = `playEpisode(slug последнего)` + плавный скролл к карточке.

**D5. Копирование RSS: `navigator.clipboard.writeText`, тост-подтверждение.**
Кнопка-ссылка в герое; при клике — копия абсолютного URL фида, тост «Ссылка на RSS скопирована» на 2 секунды (div, opacity-переход). Фолбэк: `document.execCommand('copy')` в try/catch (старые браузеры), при полной неудаче — промпт не показываем, ссылка на фид и так есть в футере. Доступность: `aria-live="polite"` на тосте.

**D6. OG-теги и фавикон.**
`og:title` = Channel.Title, `og:description` = Channel.Description, `og:type` = website, `og:url` = BaseURL, `og:image` = Channel.Image (только если задана; значение уже абсолютное по конвенции `podcast.yaml`, экранирование — `html/template` сам). Фавикон: инлайновый `<link rel="icon" href="data:image/svg+xml,...">` — скруглённый квадрат акцентного цвета с «HT» белым. Пустое состояние: «Выпуски скоро появятся» + подпись «Подпишитесь через RSS, чтобы не пропустить».

**D7. Тесты.**
Обновить `TestHomeShowsEpisode` (плеер `data-slug`, длительность в data-атрибуте, дата словами, кнопки, отсутствие `controls` у `audio`), `TestHomeEmpty` (новый текст), добавить: OG-теги (задана/не задана обложка), герой (обложка, кнопка последнего выпуска), RSS-копирование (элемент с URL фида). JS не тестируем автотестами (ручная проверка + smoke).

## Risks / Trade-offs

- [Кастомный плеер без нативного фолбэка: сломанный JS = нет прослушивания в браузере] → JS инлайновый, крошечный, без зависимостей; аудио-ссылка остаётся в DOM, «скачать/открыть» доступно всегда; smoke-прогон проверяет страницу целиком.
- [`prefers-color-scheme` не даёт ручного выбора темы] → сознательно: минимализм; переключатель добавляется позже одной кнопкой + классом на `<html>`.
- [Русские месяцы руками] → map из 12 строк в handlers.go; тест на форматирование даты.
- [OG-image без реальной обложки] → тег просто не выводится; мессенджер покажет текстовое превью — приемлемо до появления обложки.

## Migration Plan

Изменение изолировано в шаблоне, handlers и тестах. Деплой: bump `heavytech_git_ref` → `make run --limit heavytech` (compose-хендлер пересоберёт). Ролбэк — вернуть предыдущий ref. Данные и API не затронуты.

## Open Questions
