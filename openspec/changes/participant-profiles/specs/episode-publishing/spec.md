# Spec Delta: episode-publishing

## ADDED Requirements

### Requirement: Каталог участников канала

Сервис MAY описывать участников канала каталогом `people/` в корне podcast-dir: подпапка на участника, имя папки — slug участника (`^[a-z0-9]+(-[a-z0-9]+)*$`, иначе — ошибка синхронизации). В подпапке MUST быть файл `person.yaml` с полем `name` (непустая строка — ключ связи с выпусками); имена участников MUST быть уникальными, дубликат — ошибка синхронизации. `person.yaml` MAY задавать `avatar` (имя файла изображения `.jpg`/`.jpeg`/`.png`/`.webp`/`.gif` в той же папке; файл MUST существовать, иначе — ошибка синхронизации) и `description` (markdown-строка). Рядом MAY лежать `description.md`, который имеет приоритет над `description`; при обоих источниках сервис MUST логировать предупреждение. Неизвестные файлы в папке участника — ошибка синхронизации; dot-файлы игнорируются. Папка `people` отсутствует — сервис MUST работать как без неё.

#### Scenario: Участник с описанием и аватаром

- **WHEN** в `people/` есть `ivan-petrov/` с `person.yaml` (`name: Иван Петров`, `avatar: avatar.jpg`, `description: О Иване`) и файлом `avatar.jpg`
- **THEN** рескан проходит без ошибок и в индексе появляется участник `ivan-petrov` с именем «Иван Петров», описанием и аватаром

#### Scenario: Аватар не существует

- **WHEN** `person.yaml` задаёт `avatar: missing.png`, файла `missing.png` в папке участника нет
- **THEN** рескан завершается ошибкой синхронизации с указанием папки участника

#### Scenario: Дубликат имени

- **WHEN** два участника имеют одинаковое `name`
- **THEN** рескан завершается ошибкой синхронизации

#### Scenario: Каталога нет

- **WHEN** папка `people/` в podcast-dir отсутствует
- **THEN** рескан проходит без ошибок, сайт работает как раньше

### Requirement: Выпуск связывается с участником по имени

При каждом рескане сервис MUST пересчитывать связи «выпуск ↔ участник»: значение `host` и каждый элемент `guests` эпизода (после трима) сопоставляется с `name` участника точным совпадением; совпавшие участники получают роль `host` или `guest` (порядок гостей сохраняется). Имя без совпадения MUST оставаться обычным текстом — ошибка не возникает. Участник без выпусков MUST быть допустим. Связи MUST пересчитываться при каждом рескане: изменения `host`/`guests` и исчезнувшие участники отражаются в индексе.

#### Scenario: Гость найден в каталоге

- **WHEN** эпизод 7 задаёт `guests: [Иван Петров, Мария Смирнова]`, участник «Иван Петров» описан в `people/`, «Мария Смирнова» — нет
- **THEN** эпизод 7 связан с участником `ivan-petrov` (роль `guest`, позиция 1), а «Мария Смирнова» остаётся строкой без связи

#### Scenario: Рескан обновляет связи

- **WHEN** из `guests` эпизода 7 удалён участник и выполнен рескан
- **THEN** связь эпизода 7 с этим участником в индексе исчезает
