# Spec Delta: podcast-serving

## ADDED Requirements

### Requirement: Страница участника

`GET /people/{slug}` MUST отдавать страницу участника: аватар (если задан), имя и описание (безопасный markdown, как в шоу-ноутах) и список выпусков с участием — новыми сверху, каждая запись с ролью участника в выпуске (ведущий/гость). Неизвестный slug MUST отдавать 404. Страница MUST использовать общий каркас сайта (title, meta description, canonical) и MUST быть экранирована как HTML.

#### Scenario: Страница участника с выпусками

- **WHEN** участник `ivan-petrov` участвует в эпизодах 7 и 9, запрошен `GET /people/ivan-petrov`
- **THEN** ответ 200: аватар, имя «Иван Петров», описание и выпуски 9 и 7 (новым сверху) с ролями

#### Scenario: Участник без выпусков

- **WHEN** участник `maria-smirnova` описан в каталоге, но не связан ни с одним выпуском, запрошен `GET /people/maria-smirnova`
- **THEN** ответ 200: аватар, имя, описание, список выпусков пуст

#### Scenario: Неизвестный участник

- **WHEN** запрошен `GET /people/unknown-name`
- **THEN** ответ 404

### Requirement: Аватар участника раздаётся по стабильному URL

`GET /people/{slug}/avatar.{ext}` MUST отдавать файл аватара участника из его папки с Content-Type по расширению; любой другой файл участника по этому маршруту MUST отдавать 404. URL аватара MUST быть стабильным и единственным: аватар хранится один раз на участника и переиспользуется всеми выпусками, где он участвует. У участника без аватара URL MUST не предлагаться.

#### Scenario: Аватар раздаётся

- **WHEN** участник `ivan-petrov` задал `avatar: avatar.jpg`, запрошен `GET /people/ivan-petrov/avatar.jpg`
- **THEN** ответ 200 с содержимым файла и `Content-Type: image/jpeg`

#### Scenario: Чужой файл не раздаётся

- **WHEN** в папке участника лежит `notes.txt`, запрошен `GET /people/ivan-petrov/notes.txt`
- **THEN** ответ 404

### Requirement: Участники в списках выпуска кликабельны

На карточке выпуска и странице выпуска линии «Ведущий:» и «Гости:» MUST выводиться поэлементно: имя известного участника — ссылка на его страницу `/people/{slug}`, имя неизвестного — обычный текст (смешение ссылок и текста в одной линии допустимо). Архив MUST остаться без вложенных ссылок (строка выпуска целиком является ссылкой). Фиды этот change MUST не менять.

#### Scenario: Известный гость — ссылка

- **WHEN** эпизод 7 задаёт `guests: [Иван Петров]`, участник «Иван Петров» известен, запрошена страница выпуска 7
- **THEN** имя в линии «Гости:» — ссылка на `/people/ivan-petrov`

#### Scenario: Неизвестный гость — текст

- **WHEN** эпизод 7 задаёт `guests: [Мария Смирнова]`, участник не описан в каталоге, запрошена страница выпуска 7
- **THEN** имя в линии «Гости:» — обычный текст, без ссылки

### Requirement: API отдаёт участников и их список

`GET /api/episodes` MUST аддитивно дополнять каждый выпуск полем `participants`: роль (`host`/`guest`), имя и — для известных участников — `slug`, `url` страницы и `avatar` (если есть); существующие поля `host` и `guests` MUST остаться без изменений. `GET /api/people` MUST отдавать машинный список участников: `slug`, `name`, `url`, `avatar` (если есть) и `episodes` (номера выпусков с участием).

#### Scenario: Участники в выпуске API

- **WHEN** эпизод 7 задаёт `host: Иван Петров`, участник известен, запрошен `GET /api/episodes`
- **THEN** запись эпизода 7 содержит `participants` с ролью `host`, именем «Иван Петров», `slug`, `url` и `avatar`; поля `host`/`guests` остаются как раньше

#### Scenario: Список участников API

- **WHEN** запрошен `GET /api/people`
- **THEN** ответ — массив участников со `slug`, `name`, `url`, `avatar` и номерами выпусков

## MODIFIED Requirements

### Requirement: Карта сайта и robots

`GET /sitemap.xml` MUST отдавать XML-карту сайта со всеми публичными страницами: лендинг, архив, страница каждого выпуска и страница каждого участника, с абсолютными URL из `base-url` и датой публикации выпуска. `GET /robots.txt` MUST разрешать обход и указывать абсолютный URL карты сайта. Карта MUST обновляться при изменении набора выпусков и участников.

#### Scenario: Карта содержит страницы выпусков

- **WHEN** в индексе есть выпуски 7 и 9, запрошен `GET /sitemap.xml`
- **THEN** ответ 200 с XML, содержащим абсолютные URL `/`, `/episodes`, `/episodes/7` и `/episodes/9`

#### Scenario: Карта содержит страницы участников

- **WHEN** в каталоге есть участник `ivan-petrov`, запрошен `GET /sitemap.xml`
- **THEN** ответ 200 с XML, содержащим абсолютный URL `/people/ivan-petrov`

#### Scenario: robots указывает карту

- **WHEN** запрошен `GET /robots.txt`
- **THEN** ответ разрешает обход и содержит строку `Sitemap` с абсолютным URL `/sitemap.xml`

#### Scenario: Удалённый выпуск исчезает из карты

- **WHEN** эпизод 7 удалён из папки и выполнен рескан, запрошен `GET /sitemap.xml`
- **THEN** URL `/episodes/7` в карте отсутствует
