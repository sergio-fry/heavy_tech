# Proposal: site-redesign

## Why

Сайт готовится к публичному продвижению: текущая вёрстка — служебный светло-серый список, который не формирует идентичность канала и не работает на первого посетителя из мессенджера. Нужен «студийный редакционный» дизайн (современный, нейтральный, дружелюбный), который представляет канал: обложка, понятный герой-блок, удобное прослушивание и корректные превью при расшаривании.

## What Changes

- Редизайн единственной HTML-страницы (`GET /`): герой-блок с обложкой канала из `podcast.yaml` (image), названием и описанием; кнопка «слушать последний выпуск»; кнопка «скопировать ссылку на RSS» с подтверждением.
- Карточки эпизодов: плитка-заглушка с номером выпуска (CSS-градиент, без картинок), круглые кнопки play, живой прогресс-бар с перемоткой по клику (замена нативного `<audio controls>`), даты словами по-русски, счётчики — приглушённой строкой.
- Авто-темы: светлая и тёмная палитры через CSS-переменные + `prefers-color-scheme`; акцент — тёплая терракота (светлая тема) / амбра (тёмная). Системный шрифтовой стек, без webfonts и внешних зависимостей.
- Open Graph-метаданные в HTML (`og:title`, `og:description`, `og:image`, `og:type`, `og:url`) — красивые превью ссылки в мессенджерах.
- Фавикон: инлайновый SVG-знак «HT».
- Пустое состояние: аккуратная заглушка «Выпуски скоро появятся» + RSS.
- Плей-бикон `POST /track/play` сохраняется (отправляется при старте воспроизведения из кастомного плеера); аудио-эндпоинт, фид и API не меняются. **BREAKING**: нет — все внешние контракты (URL, фид, API) прежние.

## Impact

- Код: `web/index.html` (шаблон и стили), `handlers.go` (данные страницы: обложка канала, «последний выпуск», даты словами; OG-теги), JS плеера и копирования ~40 строк без библиотек.
- Спека `audience-metrics` не меняется: требование отправки play-бикона выполняется кастомным плеером так же.
- Тесты: обновить проверки HTML (новые элементы страницы, отсутствие `<audio controls>`, наличие OG-тегов), добавить проверку копирования-RSS-элемента и тем (CSS-переменные, `prefers-color-scheme`).
- Выкатка: через отлаженный конвейер — bump `heavytech_git_ref` в infra-роли → `make run --limit heavytech`.
