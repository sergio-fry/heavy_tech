# Spec Delta

## ADDED Requirements

### Requirement: Страница содержит Open Graph-метаданные

HTML-страница `GET /` MUST содержать Open Graph-теги для корректного превью при расшаривании: `og:title` (название канала), `og:description` (описание канала), `og:type` = `website`, `og:url` (базовый URL) и `og:image` (абсолютный URL обложки канала, когда она задана в `podcast.yaml`). Все значения MUST быть экранированы как HTML-атрибуты.

#### Scenario: Превью для мессенджера

- **WHEN** в `podcast.yaml` заданы название, описание и обложка, запрошен `GET /`
- **THEN** HTML содержит `og:title` с названием канала, `og:description` с описанием, `og:type` = `website`, `og:url` с базовым URL и `og:image` с абсолютным URL обложки

#### Scenario: Обложка не задана

- **WHEN** в `podcast.yaml` поле `image` пусто, запрошен `GET /`
- **THEN** HTML содержит `og:title`, `og:description`, `og:type` и `og:url`, а тег `og:image` отсутствует

## MODIFIED Requirements

### Requirement: Сайт показывает список эпизодов с плеером

`GET /` MUST возвращать HTML-страницу со списком эпизодов от новых к старым: дата словами по-русски, заголовок, описание, счётчики скачиваний и прослушиваний, встроенный плеер для прослушивания в браузере и ссылка на фид. Страница MUST содержать герой-блок канала: название, описание и обложку из `podcast.yaml` (когда обложка задана), действие «слушать последний выпуск» (запускает воспроизведение самого нового эпизода) и действие «скопировать ссылку на RSS» (помещает абсолютный URL фида в буфер обмена). Плеер эпизода MUST иметь кнопку play/pause и прогресс-бар с перемоткой по клику; при старте воспроизведения плеер отправляет `POST /track/play`. Нативный `<audio controls>` не используется. Пустой список MUST отображаться осмысленной заглушкой.

#### Scenario: Эпизод виден на сайте

- **WHEN** в индексе есть эпизод «Первый выпуск» (slug `pervyy-vypusk`, 1872 секунды), запрошен `GET /`
- **THEN** HTML содержит дату словами, заголовок, описание, плеер с `data-slug="pervyy-vypusk"` и длительностью эпизода, кнопки play/pause и счётчики эпизода

#### Scenario: Герой-блок и копирование RSS

- **WHEN** в `podcast.yaml` заданы название, описание и обложка, запрошен `GET /`
- **THEN** HTML содержит герой-блок с названием, описанием и обложкой канала, кнопку «слушать последний выпуск» со slug самого нового эпизода и элемент копирования RSS-ссылки (абсолютный URL `/feed.xml`)

#### Scenario: Пустой подкаст

- **WHEN** эпизодов нет, запрошен `GET /`
- **THEN** страница отображает заглушку «Выпуски скоро появятся» и ссылку на фид
